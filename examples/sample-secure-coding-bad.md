# Acme Corp — Secure Coding Standard

**Version:** 1.0
**Last reviewed:** 2024-01-15

## Purpose

Engineers at Acme Corp must write secure code. This document explains how.

## General principles

- Write good code.
- Don't introduce vulnerabilities.
- Use modern frameworks.
- Follow industry best practices.

## Authentication

Users must authenticate to access the application. Passwords should be strong.

## Data

Sensitive data should be protected. Don't expose customer data unnecessarily.

## Errors

Errors should be handled gracefully. The application should not crash.

## Code review

Engineers should review each other's code before merging to main.

## Tools

The team uses standard development tools. Engineers should keep them up to date.
