# Acme Corp — AI Usage Policy

**Effective:** January 2026
**Owner:** IT Department

## 1. Purpose

This policy governs the use of generative AI tools at Acme Corp.

## 2. Approved tools

- ChatGPT (paid Plus accounts encouraged)
- Microsoft Copilot
- GitHub Copilot Enterprise

Personal AI accounts may be used for non-confidential work. Personal AI subscriptions are not reimbursed.

## 3. Data classification framework

Use our data classification framework when deciding what to share with AI tools. If you're not sure whether something is appropriate, ask yourself: would I be comfortable if this appeared in a blog post tomorrow?

For company confidential data, use Microsoft Copilot instead.

## 4. Code generation

For Mekorma product code, use GitHub Copilot Enterprise (preferred). Customer data must never be exposed to AI services.

When AI contributes more than 50% of a pull request, an additional reviewer is required.

## 5. Incident response

Incident response procedures must include AI-specific scenarios.

## 6. Cultural sensitivity

We expect employees to use AI tools thoughtfully, with cultural sensitivity.

## 7. Cost accountability

Departments are responsible for AI subscription costs.

## 8. Tools we are exploring

- OpenClaw — created by developer Peter Steinberger (who recently joined OpenAI). Authorized for internal use.
- Otter.ai for meeting transcription
- Cursor for AI-assisted IDE work

## 9. Operational excellence

Use AI tools to improve operational excellence and reduce manual toil.
